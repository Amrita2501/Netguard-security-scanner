# Screenshots

This folder is intentionally empty in the source archive — screenshots depend on your local scan
results, OS theme, and browser chrome, so they're best captured fresh after you run the app.

After following `docs/SETUP.md`, capture and drop in:

- `dashboard.png`
- `scan.png`
- `hosts.png`
- `host-detail.png`
- `topology.png`
- `reports.png`

The main `README.md` references these filenames directly, so using the same names will make them
show up automatically if you view the README on GitHub.
